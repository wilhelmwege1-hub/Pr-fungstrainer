# Prüfungstrainer Bankkaufmann

Lern-App für die IHK-Abschlussprüfung **Bankkaufmann/Bankkauffrau** (Sachsen, KMK-Rahmenlehrplan 2020): 13 Lernfelder, Erklärungen, Praxisbeispiele, Übungsaufgaben mit Lösungsweg, Quiz, Karteikarten, Prüfungssimulation nach IHK-Punkteschlüssel und Formelsammlung.

**App öffnen:** https://wilhelmwege1-hub.github.io/Pr-fungstrainer/

## Als App installieren
- **iPhone/iPad:** Link in Safari öffnen → Teilen → *Zum Home-Bildschirm*
- **Android:** Link in Chrome öffnen → ⋮ → *App installieren*
- **PC:** Link in Chrome oder Edge öffnen → Installieren-Symbol rechts in der Adresszeile

Nach dem ersten Öffnen läuft die App komplett **offline**. Neue Inhalte meldet sie mit „Neue Inhalte verfügbar“.
Für den PC gibt es zusätzlich eine einzelne Offline-Datei: [pruefungstrainer-offline.html](https://wilhelmwege1-hub.github.io/Pr-fungstrainer/pruefungstrainer-offline.html).

## Daten
Der Lernstand (Häkchen, Notizen, Quiz-Ergebnisse) bleibt auf dem jeweiligen Gerät. Übertragen zwischen Geräten: in der App *App & Daten* → *Lernstand übertragen*. Dieses Repo enthält nur die veröffentlichte App (Branch `gh-pages`), keine persönlichen Daten.
